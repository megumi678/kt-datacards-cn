上传到 https://github.com/megumi678/kt-datacards-cn

1. 确认仓库可见性是 Public，目标分支是 main。
2. 在仓库页面选择 Add file → Upload files。
   如果是空仓库，可点击 uploading an existing file。
3. 打开电脑文件夹 D:\TTF\GitHub-Upload。
4. 将这个文件夹里面的文件和子文件夹拖入网页上传区。
   不要拖外层 GitHub-Upload 文件夹，不要只上传压缩包。
   如果浏览器一次文件太多，可分批：先 output，再 SavedObjects，最后其他文件。
5. 等待所有文件上传完成，在 Commit changes 中填 Add Chinese TTS assets，提交到 main。
6. 仓库首页应该直接看到 output、SavedObjects、source-patches 等目录。
7. 打开下面网址检查，应显示队伍列表 JSON：
   https://raw.githubusercontent.com/megumi678/kt-datacards-cn/main/output/team-urls.json
8. 成功后双击本目录 Install.cmd，安装 GitHub 版本的物品。
9. TTS 中：对象 → 已保存对象 → KT Chinese GitHub → 中文生成器 → 生成队伍 → 死亡天使。

这次不需要开启 Start-Chinese-TTS.cmd。
如果菜单不刷新，关闭再打开菜单或重启游戏。
不要使用桌上旧的本机测试生成器；它的脚本仍然指向 127.0.0.1。
GitHub 修改和网页上传说明：https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
